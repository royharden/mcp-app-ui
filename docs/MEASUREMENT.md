## Units and accounting rules

| Unit | Rule |
|---|---|
| Tool calls | Counted per mode |
| Host/view messages, UI actions | Counted separately from tool calls |
| Model-visible characters | Text content forwarded to the model. In UI mode this includes the launch tool's text fallback. Card labels are not the total context. |
| Tokens | Only from named telemetry or a documented tokenizer; otherwise "unavailable" |
| Wall time | Only from real runs |

## Decision demonstrations
